# Contributing

Hive identity: `github/beadhive/agent-plugin`; prefix: `bh-ap`; kind: `org-native`.
The default and integration branch is `main`.

Run `bh hive ready -v` to verify local onboarding. Track work in beads and use
`bh work` with Agentic Git Flow; land changes as merge commits. This hive uses
the standard minimal, zero-footprint onboarding: agent instructions and role
skills come from user-scope tooling rather than copied repository furniture.
A fresh clone requires local hive onboarding before `bh work` can drive it.

Author skills in the private `beadhive/skills` source after migration validation.
Do not hand-edit future generated artifacts. Public output must contain only
explicitly allowlisted artifacts; see README.md.
